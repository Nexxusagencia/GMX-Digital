# GMX Digital — Landing Page

Landing page institucional da GMX Digital. Arquivo único, sem dependências externas.

**Publicado em:** https://nexxusagencia.github.io/GMX-Digital/

## Como atualizar

Substitua o `index.html` por completo e faça commit. Não há build, nem dependências, nem assets externos — fontes, logos e imagens estão embutidos no próprio arquivo.

Após o commit, o GitHub Pages leva 1–2 minutos para publicar. Se o navegador insistir na versão antiga, acesse com `?v=2` no fim da URL.

## Conferir a versão publicada

Veja o código-fonte da página e procure a meta `lp-version`:

```html
<meta name="lp-version" content="2026-09-11-v8">
```

## Estrutura

```
index.html     a landing page completa
.nojekyll      desliga o processamento Jekyll do Pages
.gitignore
```
